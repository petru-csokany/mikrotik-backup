MikroTik Backup is a personal utility for copying encrypted MikroTik RouterOS configuration backup files to its operator’s Google Drive, using rclone.

This website explains the application and its data practices. The backup utility runs on the operator’s devices; this website does not run backups or request Google account access.

How the backup works

  1. RouterOS creates a password-encrypted configuration backup on the operator’s device.
  2. The operator authorizes the utility through Google OAuth. The local rclone configuration holds the authorization tokens.
  3. The utility uploads the encrypted backup to Google Drive and manages the files and folders it creates.
  4. The operator can download a backup and restore it with RouterOS, using the backup password.

Limited Google Drive access

The application requests https://www.googleapis.com/auth/drive.file. In this workflow, it accesses files and folders created by this application. It does not request access to the operator’s entire Drive, Gmail, contacts, or calendar.
