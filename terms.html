Terms of use

MikroTik Backup is an independent personal automation project operated by Petru Csokany. It copies encrypted RouterOS configuration backups to the operator’s own Google Drive.

Personal and authorized use

The utility is intended for the operator’s own devices and Google account. It is not a public backup hosting service and does not offer public user registration. Google authorization must be granted by the account holder.

Backup operation

The operator controls the backup schedule, Google authorization, file retention, and local device configuration. The operator is responsible for keeping the backup encryption password recoverable, monitoring backup jobs, checking uploaded files, and verifying that a backup can be restored on suitable equipment.

Storage of a file alone does not establish that a backup is complete or usable. This personal project provides no service-level commitment, continuous monitoring service, or guarantee of data recovery.

External services

Google Drive, GitHub Pages, RouterOS, and rclone are subject to their respective terms, availability, permissions, and technical limits. This project is not affiliated with or endorsed by their providers.

Stopping use

The operator may stop the backup jobs, revoke Google access, and delete backup files at any time. The project may be changed or discontinued. Its handling of Google user data is described in the privacy policy.
