Privacy policy

MikroTik Backup is a personal utility operated by Petru Csokany. Its purpose is to store encrypted RouterOS configuration backups in the operator’s own Google Drive.

Google user data accessed

The application requests the Google Drive permission https://www.googleapis.com/auth/drive.file. In the configured backup workflow, it creates, lists, reads, updates, and deletes its own backup files and folders. It processes encrypted backup contents and file metadata, such as names, sizes, identifiers, and modification times, for those files and folders.

The application does not request access to Gmail, contacts, calendar, or all files in Google Drive. Google handles account sign-in; the backup utility does not collect the Google account password.

How data is used

Data is used only to upload backups, verify transfers, organize the backup archive, download backups when requested, and remove backup copies according to the operator’s retention settings. Operational logs may contain file names, timestamps, and transfer or error information.

Google user data is not sold, used for advertising, used to train artificial intelligence models, or shared with other users by this application.

Storage and transfer

RouterOS encrypts backup files locally with a password before this workflow uploads them. The backup password is not sent to Google Drive by the upload utility. The encrypted files and their metadata are stored in the operator’s Google Drive. Google applies its own service terms and privacy practices to that storage.

OAuth access and refresh tokens are stored in the operator’s local rclone configuration on the devices running the backup utility. They are not stored in this public website or its source repository. The backup utility communicates with Google’s API over HTTPS.

Retention, deletion, and revocation

Backup retention is controlled by the operator’s configuration. The operator can delete backup files directly in Google Drive; Google Drive’s normal trash and deletion rules apply. Local backup files and logs can be removed on the devices that store them.

The operator can revoke the application’s permission from Google Account connections. Revoking access stops future authorized access; it does not automatically delete existing backup files. The local OAuth configuration can also be removed when the utility is no longer used.

This website

These informational pages do not include analytics scripts, advertising, forms, or a Google sign-in flow. They do not receive backup files or OAuth tokens. GitHub Pages hosts the website and may process technical request information under the GitHub Privacy Statement.

Contact and updates

For questions about this application or its data practices, contact the operator through the petru-csokany GitHub profile. This policy will be updated if the application’s data practices change.

MikroTik Backup is an independent personal project, not a product of MikroTik or Google.
